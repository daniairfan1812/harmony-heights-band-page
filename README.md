# Harmony Heights: Official Band Page

A static webpage for a fictional band, built with semantic HTML5.

🔗 **Live Demo:** https://daniairfan1812.github.io/harmony-heights-band-page/

## Features
- Band introduction with images (accessible alt text)
- Audio player and video player (`<audio>`, `<video>`)
- Upcoming tour dates list with ticket links (opens in a new tab)
- Social media links
- Contact form (name, email, subject, message)

## Concepts Practiced
- HTML5 document structure and meta tags
- Headings, paragraphs, images, links and lists
- Multimedia elements
- Forms with labels, input types and textarea

## How to Run
Download `index.html` and open it in any browser.

## Tech Used
- HTML5
- GitHub Pages (hosting)
